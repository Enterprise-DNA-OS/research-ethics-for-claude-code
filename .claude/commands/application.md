# /application

Run:

```bash
node scripts/research-ethics.mjs application <reference, title or investigator>
```

Read the full history before drafting anything about it. Summarise where it stands in one line first.

Use `--json` when combining results. On an ambiguous name, list the candidates and ask; never pick the first. Nothing here sends a letter or an email: drafts go to `drafts/` and a person sends them.
