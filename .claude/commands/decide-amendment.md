# /decide-amendment

Run:

```bash
node scripts/research-ethics.mjs decide-amendment <AMD-0001> <approved|declined|withdrawn>
```

A change that adds animals or sites needs the committee, not only the office: check the profile and terms.

Use `--json` when combining results. On an ambiguous name, list the candidates and ask; never pick the first. Nothing here sends a letter or an email: drafts go to `drafts/` and a person sends them.
